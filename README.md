# Sonny Boy Del Rosario — Portfolio

A React/Vite portfolio that presents Sonny's manufacturing, inventory, logistics, and procurement systems as connected operational tools.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

Open the local address Vite prints (normally `http://localhost:5173`).

## Production build

```powershell
npm.cmd run build
```

The deployable static site is generated in `dist/`. Project screenshots, portrait, and downloadable CV are self-contained under `public/`.
